# Tailor

A framework for building malleable SaaS products. See [readme.md](readme.md).

The project is at the requirements stage. There is no framework code, and none should be written until the
requirements say so.

- `docs/02-requirements.md` is the source of truth. Each requirement is Decided, Proposed or Open.
- `docs/07-decisions.md` is append-only. Don't mark a requirement Decided without an entry there, and don't add an
  entry for something the project's owner has not settled.
- `docs/01-concepts.md` defines the vocabulary. Use its words with its meanings.
- `examples/todo` is a sketch that does not run. Keep it in step with the requirements.
- Name files and folders in kebab-case.
- [contributing.md](contributing.md) says how a change is made.
