## Not verified

- `release.yml` publishing for real, and trusted publishing. Neither can run until the owner sets up the trusted
  publisher on npmjs.com for each package and a merge bumps a version. The first such merge is the test. If it
  fails, it fails at `npm publish` with nothing published, and a rerun of the job is safe because the script skips
  versions already on npm.
- The workflows running on GitHub. `versions.yml` runs on this PR. `release.yml` runs only after the merge.
- `npm ci` with a bumped version and a lockfile that wasn't updated. `dev.md` tells the bot to run `npm install` so
  the lockfile matches. I didn't check whether `npm ci` would reject a stale lockfile.
- Render, compile and replay: this change touches none of `packages/`.

## Gaps

- verify-thixo has no feature for release tooling or CI workflows. Everything above was driven by hand.
- There's no way to run `release.yml` without publishing. A `workflow_dispatch` input for `--dry-run` would allow it.
