## Verified

- **site (not in the map): the built site shows five escape pairs, each with its compile error.**
  `npm run build -w @thixo/site`, copy `packages/site/dist` to `<host>/thixo`, run `python3 -u -m http.server 0 --directory <host>`, and open `http://127.0.0.1:<port>/thixo/` in headless Chromium (Playwright, `$RUN/scratch/drive.ts`).
  Saw: five `#escapes .escape` blocks: "Read the page's cookies", "Read a password field on the page", "Send a request to another server", "Run code from a string" and "Send the page somewhere else". Each shows the JavaScript, the thx and an error, for example `main.thx:2:14 thixo/no-global \`document\` does not exist in the language. ...` / `hint: Render elements with JSX instead.` The server log shows only `GET /thixo/`, `/thixo/assets/site.css` and `/thixo/assets/main.js`, all 200. `pageErrors: []`. The only request not to `http://` is the same-origin `blob:` that `@thixo/react`'s `load` makes for the spinner. The screenshot `escapes.png` shows each pair side by side with its error.

- **compile: the error on the page is the text `thixo compile` prints.**
  `.claude/skills/verify-thixo/scripts/cli.sh $RUN cli-<id> -- compile packages/site/programs/escapes/<id>` for each of `read-cookie read-dom network-out run-script navigate`, then `$RUN/scratch/compare.ts` compares each `stderr.txt` with the page's error text.
  Saw: `exit 1` for all five. All five read `page == cli`. For example, `run-script` gives `main.thx:2:26 thixo/forbidden-field \`constructor\` is not a field in the language: a record has only the fields it was given.` / `hint: Use another name.`

- **site: the JavaScript side really works on a page.**
  On the same page, `page.evaluate` plants `document.cookie = "session=planted"` and a password input holding `hunter2`, then runs the bodies of the JS escapes.
  Saw: `cookie: "session=planted"`, `password: "hunter2"`, `new Function("return document.cookie")()` → `"session=planted"`, `typeof fetch: "function"`, `typeof window.location.href: "string"`.

- **tests: the site test fails if an escape compiles or if the page drifts from the compiler.**
  Mutant 1: `read-cookie/main.thx` replaced with `return <p>hi</p>`. `npm test -w @thixo/site` gave `not ok 2 ... read-cookie must not compile`, `# fail 1`. Mutant 2: the page's error text has ` (stale)` appended. That gave `not ok 2` with a diff on `Render elements with JSX instead. (stale)`, `# fail 1`. With both reverted: `# pass 2`, `# fail 0`.

- **tests: the whole suite, build and typecheck.**
