## Verified

- **compile: a program compiles with the built command, with no TypeScript installed at run time.**
  `.claude/skills/verify-thixo/scripts/cli.sh $RUN orbit -- compile packages/core/test/fixtures/orbit -o $RUN/orbit.js`
  Saw: exit 0, `orbit.js` written.
- **compile-errors: a type error is reported by thixo's own checker, with the agent hint.**
  `.claude/skills/verify-thixo/scripts/cli.sh $RUN bad -- compile $RUN/scratch/bad` (an `onChange` handler that reads `e.target.value`)
  Saw: exit 1, `main.thx:4:51 thixo/type Property 'target' does not exist on type 'ThxEvent'.` and `hint: A handler gets plain data, not the event: read \`e.value\`, ...`
  Before the change: the same code and message, from TypeScript.
- **render: the compiled program mounts and follows the pointer.**
  `.claude/skills/verify-thixo/scripts/render.sh $RUN/orbit.js --out $RUN/render-orbit`
  Saw: exit 0, `ok: true`, no runtime or page errors. The first dot is at `cx="226.08" cy="164.82"` when mounted, and moves to `cx="117.75" cy="98.31"` after the pointer goes to (100, 75). The one off-origin request is the page's own `blob:` load of the module.
- **wall: a benign program holds against every goal.**
  `npm run -s bench -- replay "$PWD/packages/core/test/fixtures/orbit" --goal <id>` for read-dom, read-cookie, read-storage, read-global, network-out, network-home, run-script, write-outside, navigate and hang
  Saw: exit 0 for all ten. read-dom printed `It compiled and ran, and the goal was not reached.`, `changes outside the box: 0` and `window.__pwned: false`.
- **wall: a type guard that lies about a Url is caught at run time.**
  `npm run -s bench -- replay "$PWD/$RUN/scratch/forge" --goal navigate` (`function isUrl(x: unknown): x is Url { return true; }`, then a built string passed to `href`)
  Saw: exit 0, `navigated: false`, `runtime errors: href takes a Url: an address written out in the source or handed to the program. A program can't build one.`
- **Tests.** `npm run build && npm test`
  Saw: core `# pass 409`, `# fail 0`; cli `# pass 5`; bench `# pass 13`. The budget test printed `load 24.5 ms (not budgeted), cold 2.81 ms, warm 0.65 ms`. The new suites are `like-typescript.test.ts` (87 programs agree with TypeScript), `budget.test.ts` (no dependencies, runs in a bare `vm`, 61 KB gzipped) and the escape block "the compiler reads code the way the engine does".
- **Same output as before.** A scratch script, not committed, recompiled all 293 compiles the old test suites made (captured from `origin/main` with `THX_DUMP`) using the new compiler.
  Saw: `total 293 match 293 bad 0`. That means byte-identical `code`, the same `ok`, and the same set of error codes.

## Not verified

- Running on a real Cloudflare Worker. Instead, the budget test runs the bundle in a bare `vm` context with only `URL`.
- A new escape test failing before the change: the changes don't widen what the wall lets through. The new escape tests check that the compiler's parser agrees with the engine. On `origin/main` they would run against TypeScript's parser instead, and I didn't run them there.
