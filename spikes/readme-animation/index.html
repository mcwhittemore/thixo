The wordmark as a network, looping

The cast

Four animals work the word in turn, each coming in from off the canvas, slow to start and fast once moving. Gel only changes where an animal has been, and each animal leaves one letter alone. The honey bee weaves through the letters, leaving a serif italic, and turns away before the o. The frog leaps from letter to letter, clean over the i; each letter dips under it like a lily pad and flows into a typewriter face when it kicks off. The barn swallow drops in past the t and the wind off its wings blows the gel into a marker hand, except the x, which it blows back to how it started. Then the mud dauber wasp writes the rest of the word back, stroke by stroke, never touching the x. The last frame is the first frame, so the loop has no cut.
